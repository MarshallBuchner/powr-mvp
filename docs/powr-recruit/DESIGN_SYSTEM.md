# POWR Recruit — Design System

## Brand feel
Premium hockey development.
Dark.
Technical.
Credible.
Modern.
Athletic.

## Core palette
Background:
- #050706
- #0B0E0C
- #111512

Text:
- #FFFFFF
- #D7DDD8
- #9AA39C

Accent green:
- #52F06A
- #72FF82

Borders:
- rgba(255,255,255,0.08)
- rgba(82,240,106,0.28)

## Typography
Headlines:
- bold condensed athletic sans if available
- otherwise use a strong modern sans

Body:
- Inter / Geist / similar clean sans

## Buttons
Primary:
- bright green background
- black text
- rounded but not pill-like unless matching existing POWR
- strong hover state

Secondary:
- transparent
- subtle white border
- white text

## UI cards
- dark graphite
- thin border
- small shadow
- subtle green hover glow only
- 16–24px radius depending on existing app

## Photography
Preferred:
- realistic hockey
- bench / tunnel / rink
- player looking at phone or laptop
- equipment texture
- ice surface
- natural dramatic lighting

Avoid:
- cheesy stock-photo smiles
- fake NHL branding
- identifiable logos without rights
