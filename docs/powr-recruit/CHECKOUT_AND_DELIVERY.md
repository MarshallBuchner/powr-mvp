# Checkout & Delivery

## Preferred launch options
Fastest:
- Gumroad
- Lemon Squeezy

More integrated:
- Stripe Checkout

## Flow
1. User clicks CTA
2. Checkout
3. Successful purchase
4. Redirect to `/recruit/thank-you`
5. User receives email receipt/download link
6. Download page offers files
7. Optional reel-review upsell
